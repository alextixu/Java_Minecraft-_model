Mob Armory 後台

武器和怪物改了以後立刻套用到遊戲裡，並寫回 config/mobarmory/

伺服器上的武器

    從左邊選一把武器來編輯。

    新增武器

    新的武器會存成 config/mobarmory/weapons/<id>.json。Minecraft 只在啟動時建立物品種類，所以重開遊戲後才能用 /give 拿到。

    每種怪物是 config/mobarmory/mobs/<id>.json 的一個檔案。存檔後，名稱、數值、大小立刻套用到世界上的同種怪物；行為和裝備等下次生成才生效；身體要重開遊戲才能換。

    伺服器上的怪物

      從左邊選一種怪物來編輯。

      新增怪物

      新的怪物會存成 config/mobarmory/mobs/<id>.json。Minecraft 只在啟動時建立生物種類，所以重開遊戲後才能用生怪蛋或 /summon 生出來。不用改任何程式。
