Mob Armory 武器後台

改了以後立刻套用到遊戲裡所有同種武器，並寫回 config/mobarmory/weapons/

伺服器上的武器

    從左邊選一把武器來編輯。

    新增武器

    新的武器會存成 config/mobarmory/weapons/<id>.json。Minecraft 只在啟動時建立物品種類，所以重開遊戲後才能用 /give 拿到。

    伺服器上的怪物

    這裡只能查看。怪物定義在模組的程式裡（content/ModMobs.java），要新增或修改怪物，請照 README 的「加一隻怪物」改程式，再重開遊戲。裝備欄寫的是武器的 id，武器本身可以在「武器」分頁修改。
