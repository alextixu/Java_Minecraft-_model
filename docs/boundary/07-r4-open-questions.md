## 第一輪：設計（3 題）

### Q1 SOLID 判斷

我預期照最直接的寫法，會出現兩個徵兆：

- 每加一種怪物就多一個 `XxxEntity` 類別和渲染器（O）。
- 每加一種行為就要在怪物的 `registerGoals` 裡加 `if`（O）。

另外要避免怪物自己寫一套血量、速度欄位，和 R1 的數值系統重複（S、D）。

處方：怪物是資料，由 `MobEntityFactory` 建出生物種類；行為各自是 `Behavior` ＋ `GoalBinder`；數值全部走 R1 的登記表。詳見 [05 第 3 節](05-r4-boundary-note.md#solid-判斷第一輪-q1-要確認)。

- **A（建議）** 同意
- B 不是這個問題，是……（請說明）
- C 這次不要重構，直接加

### Q2 Pattern 選擇

會變的是：怪物清單和數值、行為的種類、外觀。

- **A（建議）** 每筆定義註冊一個生物種類（Factory）；行為用 Strategy（`Behavior` ＋ `GoalBinder`）；外觀從原版人形模型挑。每種怪物有自己的 `/summon mobarmory:<id>` 和生怪蛋。新的怪物**種類**要重開遊戲才生效（平台限制）；數值和行為之後都能由 R6 網頁改。
- B 只註冊一個通用生物種類，用「變體 id」決定是哪種怪物。R6 網頁可以在遊戲執行中直接建立新怪物，但變體要自己存檔和同步，`/summon` 要帶參數，約多半天。
- C 直接寫、不抽象：每種怪物一個類別（例如 `BruteEntity extends Zombie`）。今天最快，但 R6 網頁設定行為時要大改。

### Q3 變更邊界

**打算動的檔案**（不同意的請劃掉）：

- 新建 `core/mob/`（`MobDefinition`、`Behavior`、`MobLook`、`MobCatalog`）、`content/ModMobs`、`forge/` 的 `MobEntityFactory`、`ArmoryMob`、`BehaviorGoals`、`forge/client/` 的渲染器
- `content/ModStats` 加一筆「最大生命值」（對應原版 `max_health`）
- `MobArmoryMod` 加接線；語系檔加怪物和生怪蛋的名稱
- `src/gametest` 加 R4 的系統測試

**認為不能動的**（還有要補的請加上）：

- R1／R2 已確認的 `core/stat`、`core/equipment`、`core/combat` 的公開介面和規則
- `EquipmentStatApplier`、`CombatEffectListener`、`EntityStatBinder` 的行為（怪物直接用它們，不另寫一套）
- Minecraft 和 Forge 本身（不用 Mixin）

**新功能放的位置**：新怪物放 `content/ModMobs`，新行為放 `core/mob` 的 `Behavior` 加 `forge` 的 `GoalBinder`。

## 第二輪：商業規則（4 題，最影響實作的）

### Q4 外觀怎麼「設定」

- **A（建議）** 從原版人形模型挑一個（殭屍、屍殼、骷髏、流髑），加上大小倍率（例如 1.2 倍）。不用畫圖，週日前做得完；R6 網頁可以在這幾種之間切換。
- B 原版模型，但每種怪物配一張自己的貼圖。需要有人畫圖（AI 產生的貼圖品質不穩），每多一種怪物就多一張圖。
- C 自製模型（Blockbench 或 GeckoLib）。外觀最自由，但要多一個相依套件和一套動畫，週日前做不完。

### Q5 怪物怎麼出現

- **A（建議）** 雛型只用生怪蛋（放在 Mob Armory 分頁）和 `/summon`，不自然生成。驗收和示範時可以精準控制在哪裡、生幾隻。
- B 也在夜晚的平原、森林等地方自然生成，數量規則照原版怪物。比較像真的遊戲，但測試和示範時不好控制，也要決定生成權重。

### Q6 R6 網頁改了定義以後，已經在世界上的怪物怎麼辦

（和 R2 的 Q6「同種裝備共用一份定義」同一個方向）

- **A（建議）** **數值**立刻生效（下次重算時套用）；**行為**等這隻怪物下次生成或世界重新載入才生效。原版的 AI goal 是在生物建立時決定的，中途換掉容易出錯。
- B 數值和行為都立刻生效：改定義時，把世界上同種怪物的 goal 全部清掉重建。比較直觀，但要處理「正在追玩家時行為被換掉」等狀況，多約半天。

### Q7 攻擊誰

- **A（建議）** 主動攻擊附近 16 格內的生存或冒險模式玩家；被任何生物打了會反擊；不主動攻擊其他生物。創造、旁觀模式不攻擊（原版規則）。
- B 只攻擊玩家，被其他生物打也不反擊。
- C 也主動攻擊村民、鐵魔像（像原版殭屍）。
