# 邊界行為：Given / When / Then（R4b 怪物資料檔＋網頁設定，A6、A7，T2）

> 狀態：**主 session 依使用者夜間授權採用建議值（2026-11-07），待使用者確認**。標「請確認」的 Then 欄都採用建議值，題號對應 [23](23-r4b-mob-admin-open-questions.md)。每一列都會變成一個測試，測試的說明文字照抄這裡的三行，對應的測試名稱列在行為報告 [28](28-r4b-mob-admin-behavior-report.md)。
> 流程：boundary-first 第 3 步。邊界說明在 [21](21-r4b-mob-admin-boundary-note.md)。

## 數字的前提

- 預設的兩個怪物檔，數字和 R4 完全一樣（[06](06-r4-given-when-then.md)、[07](07-r4-open-questions.md) 的 O1）：

| 檔案 | 名稱 | 外觀 | 最大生命 | 攻擊力 | 移動速度 | 暴擊率 | 迴避率 | 裝備 | 行為 |
|---|---|---|---|---|---|---|---|---|---|
| `brute.json` | Brute | 殭屍，1.2 倍 | 40 | 4 | 0.25 | 0 | 0 | 主手重劍 | 閒晃、攻擊玩家 |
| `skirmisher.json` | Skirmisher | 屍殼 | 16 | 2 | 0.32 | 0.25 | 0.30 | 主手短刀 | 閒晃、攻擊玩家 |

- 證明 T2 用的測試怪物 `goblin.json`，只有 JSON，沒有任何 Java 或資源檔：屍殼 0.8 倍、生命 12、攻擊 3、速度 0.3、主手短刀；行為是閒晃、中立（追擊速度 1.3）、衝刺。
  - 拿短刀後：攻擊 3 ＋ 2 = 5，暴擊 0 ＋ 0.25 = 0.25，速度 0.3 × 1.1 = 0.33。
- 狂戰士拿重劍：攻擊 4 ＋ 6 = 10，速度 0.25 × 0.7 = 0.175（R4 的 H2）。
- 怪物打玩家的傷害依難度縮放，傷害相關的測試都在**普通**難度。

## 成功條件（玩家自己加的一種怪物正常運作，要同時成立的事）

1. 檔案合法：
   - 嚴格 JSON，`format` 是 1，沒有不認得的欄位，檔名是合法的 id。
   - 名稱不空。
   - 身體是四種之一，大小在範圍內。
   - 數值只引用登記表裡有的，而且在範圍內。
   - 欄位名稱合法。
   - 行為是認得的種類，參數合法、沒有重複、組合合理。
2. 啟動時在資料夾裡，就會註冊生物種類和生怪蛋，出現在 Mob Armory 分頁，可以 `/summon mobarmory:<id>`。
3. 生成時：
   - 數值照檔案；沒寫的用預設值。
   - 裝備照檔案；武器缺少時照 07 第四輪處理。
   - 行為照檔案。
4. 名稱照檔案顯示，生怪蛋叫「<名稱> Spawn Egg」，蛋的外觀是那種身體的原版蛋。
5. 網頁列得出來，看得到狀態；改了就先寫檔再套用；新增就寫檔，標待重開。
6. 執行中改了定義以後：
   - 名稱、數值、大小立刻作用在世界上的同種怪物。
   - 行為、裝備等下次生成或從存檔載入。
   - 身體等重開。
7. 重新載入：重讀檔案，全有或全無；新檔等重開；被刪的檔保留到重開。
8. 多人：其他玩家的電腦看到一樣的名稱；數值和大小由原版同步。
9. 存檔再載入：數值跟著現在的定義，不疊加。

H 系列是全部條件成立的情況，B 系列是逐一破壞上面的條件推導出來的。

## 還沒列進來的（這一輪不做）

- 刪除怪物的按鈕：網頁沒有，和武器一樣（23 的 O19）。
- 追擊距離開放設定：建議固定 16 格（23 的 O8）。
- 中立的怪物被打時，叫附近同種一起來：建議不做（23 的 O5）。
- 自然生成、掉落物、自製貼圖或模型：07 的 Q4、Q5、O7 不變。
- 換身體立刻生效（渲染器跟著換）：建議等重開（23 的 O9）。
